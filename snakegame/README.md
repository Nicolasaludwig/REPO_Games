# Neon Byte-Snake

**Como jogar:** Use as setas do teclado para guiar a cobra, comer os blocos e crescer sem bater nas paredes ou no próprio corpo.
**O diferencial:** Introduz mecânica de risco-recompensa com "Comidas Douradas" temporárias e um Leaderboard local para disputas no mesmo PC.
**Créditos:** Desenvolvido como estudo de Level Design e Game Loop (JavaScript/Canvas).
